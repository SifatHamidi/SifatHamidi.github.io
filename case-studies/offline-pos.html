Offline Point of Sale on Odoo 14

Keeping checkout running when the internet or server connection drops — without losing orders or creating duplicates once the store comes back online.

Platform
Odoo 14
Area
Point of Sale
Stack
JavaScript · Python

The problem

A retail Point of Sale is only useful if it keeps working at the counter. The client's stores could not rely on a stable connection to the Odoo server, and every outage meant stalled checkouts, manual workarounds and the risk of lost or mismatched sales.

The goal: cashiers should be able to keep selling normally while offline, and every order must reach the server exactly once when the connection returns.

The approach

Orders always go to a local queue first, then sync to Odoo when the connection allows.

  • Cache what checkout needs. Products, prices, taxes and customers are loaded when the session starts, so the POS can complete a sale without asking the server.
  • Queue every order locally. Each completed order is written to browser storage first, so a dropped connection or a closed tab never loses a sale.
  • Sync automatically. When the connection returns, queued orders are sent to Odoo in batches, with retries for any that fail.
  • Keep cashiers informed. A clear online/offline status and a count of pending orders show staff exactly what still needs to sync.

Key decisions

Client-generated order IDs

Each order gets a unique ID on the device at the moment it's created. The server uses it to recognize orders it has already received, so retries and repeated syncs can never create duplicate sales.

Local-first, server-confirmed

An order is removed from the local queue only after the server confirms it was saved. Until then it stays on the device, which keeps data safe through crashes and reloads.

Be clear about what needs the server

Actions that depend on live server data can't be fully trusted offline. Instead of guessing, those are limited or deferred while offline, so the core flow — scanning, pricing, payment and receipt — stays reliable.

Outcome

Stores keep selling through connection drops, and orders reach Odoo automatically once the connection is back — without manual re-entry and without duplicate records.
